# Alessandro Rizza — Portfolio

Visual & Motion Designer. Venice, Italy.

## Pubblicare su GitHub Pages

1. Carica il contenuto di questa cartella nella radice del repository.
2. Settings → Pages → Source: branch `main`, cartella `/ (root)`.
3. Dopo qualche minuto il sito è online.

## Struttura

- `index.html` — Home
- `about.html` — About
- `support.js` — runtime necessario a entrambe le pagine
- `assets/` — logo, favicon
- `uploads/` — video e immagini

Font: Neue Haas Grotesk Display via Adobe Fonts (web project yui0tba).
